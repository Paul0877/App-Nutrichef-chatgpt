# Nutrichef

Aplicación web estática de recetas saludables, lista para publicar en GitHub Pages.

## Contenido
- `index.html`: estructura de la aplicación.
- `styles.css`: diseño adaptable a móviles, tabletas y escritorio.
- `script.js`: catálogo de 8 recetas, filtros, búsqueda y ventanas de detalle.

## Publicar en GitHub Pages
1. Descomprime `Nutrichef-GitHub-Pages.zip`.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz de tu repositorio de GitHub.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, luego guarda.
6. Espera a que GitHub Pages publique el sitio.

Las fotografías se cargan desde Unsplash mediante internet, por lo que deben estar disponibles al visitar la página.
